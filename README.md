# Data Analyst Internship – Task 1

## Project Title

Data Cleaning and Preprocessing using Python

## Objective

The objective of this project is to clean and preprocess a messy customer sales dataset to improve data quality and make it suitable for analysis.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Data Cleaning Steps

1. Checked missing values.
2. Handled missing values.
3. Identified and removed duplicate records.
4. Standardized text values.
5. Standardized date formats.
6. Corrected data types.
7. Renamed column headers.

## Project Files

* Sales-data-clean.ipynb – Python cleaning process.
* cleaned_dataset.csv – Final cleaned dataset.

## Outcome

Successfully performed data cleaning and preprocessing using Python Pandas.
